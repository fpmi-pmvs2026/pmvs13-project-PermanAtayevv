# HabitTracker (Трекер привычек)

## Description
HabitTracker — это мобильное приложение для ОС Android, разработанное для формирования полезных привычек и отслеживания ежедневного прогресса. Приложение позволяет пользователям создавать новые привычки, отмечать их выполнение с помощью удобного тач-интерфейса и просматривать общую статистику. Для дополнительной мотивации реализована загрузка ежедневных цитат из сети Интернет и система локальных уведомлений-напоминаний. Проект демонстрирует использование многооконного интерфейса, базы данных SQLite (Room), многопоточности и сетевого взаимодействия (Retrofit).

## Installation
Чтобы установить приложение локально, выполните следующие шаги:
1. Склонируйте данный репозиторий на свой компьютер: `git clone <ссылка_на_ваш_репозиторий>`
2. Откройте проект в среде разработки **Android Studio** (версии Flamingo и выше).
3. Дождитесь окончания синхронизации Gradle (потребуется подключение к интернету для загрузки библиотек Room, Retrofit, Navigation).
4. Подключите Android-смартфон по USB или запустите виртуальный эмулятор (AVD).
5. Нажмите кнопку **Run (Shift + F10)** для компиляции и установки APK-файла на устройство.

## Usage
* **Добавление привычки:** На главном экране нажмите круглую кнопку `+` в правом нижнем углу. Введите название привычки и сохраните.
* **Отметка о выполнении:** Поставьте галочку рядом с привычкой, чтобы отметить её как выполненную на сегодня.
* **Удаление:** Смахните (свайпните) карточку привычки влево или вправо для её удаления из базы данных.
* **Статистика:** Перейдите на вкладку "Статистика" в нижнем меню, чтобы увидеть ваш прогресс (всего создано / выполнено сегодня).
* Приложение автоматически присылает уведомление каждый вечер, напоминая зайти и отметить привычки.
